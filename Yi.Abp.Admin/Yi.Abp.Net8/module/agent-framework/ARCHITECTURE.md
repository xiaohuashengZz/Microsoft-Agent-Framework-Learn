## 1. 全景架构图:从 LLM 到业务

```

└────────────────────────────────────────────────────────────────────┘
                                  │
```

### 各层作用

| 层级 | 作用 | 谁负责 |
|------|------|--------|
| **业务层** | 对外提供 HTTP API,接收用户请求 | ABP AppService |
| **编排层** | 把多个 Agent/Executor 连成图,驱动执行 | WorkflowBuilder |
| **Agent 层** | 封装 LLM 调用,提供身份/记忆/工具 | ChatClientAgent |
| **抽象层** | 定义 IChatClient 接口,屏蔽 LLM 差异 | Microsoft.Extensions.AI |
| **Provider 层** | 适配具体 LLM 服务 | OpenAIClient 等 |
| **LLM 服务层** | 实际的 AI 模型推理 | DeepSeek/OpenAI 等 |

## 2. 技术栈分层图:五层抽象

```
┌─────────────────────────────────────────────────────────────┐
│  你的业务代码                                                │
│  (ABP AppService / Runner / Controller)                     │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  AgentFrameworkAppService                           │    │
│  │  ├── HelloWorldRunner     ← 单 Agent                │    │
│  │  ├── SequentialWorkflowRunner ← 顺序工作流          │    │
│  │  └── ParallelWorkflowRunner  ← 并行工作流           │    │
│  └─────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│  Microsoft Agent Framework (MSAF)                           │
│  NuGet: Microsoft.Agents.AI.OpenAI                          │
│  ┌─────────────────┐ ┌──────────────┐ ┌─────────────────┐  │
│  │   AIAgent       │ │ AgentThread  │ │ Workflow        │  │
│  │   (智能体抽象)  │ │ (对话线程)   │ │ (工作流编排)   │  │
│  │                 │ │              │ │                 │  │
│  │ ChatClientAgent │ │ - 维护历史   │ │ - WorkflowBuilder│ │
│  │ - Instructions  │ │ - 序列化     │ │ - Executor      │  │
│  │ - Name          │ │ - 跨会话     │ │ - Edge(4种)     │  │
│  │ - Tools         │ │              │ │                 │  │
│  └─────────────────┘ └──────────────┘ └─────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│  Microsoft.Extensions.AI (MEAI)                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  IChatClient  ← 核心抽象接口                         │    │
│  │  AIFunction   ← 工具抽象                             │    │
│  │  ChatMessage  ← 消息抽象                             │    │
│  └─────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│  LLM Provider 实现                                           │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  OpenAIClient (System.ClientModel)                  │    │
│  │  ├── 对接 OpenAI 官方                                │    │
│  │  ├── 对接 DeepSeek (OpenAI 兼容)                    │    │
│  │  ├── 对接 Ollama (OpenAI 兼容)                      │    │
│  │  └── 对接通义千问 (OpenAI 兼容)                     │    │
│  └─────────────────────────────────────────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│  实际 LLM 服务                                               │
│  DeepSeek API  /  OpenAI API  /  本地 Ollama  /  vLLM       │
└─────────────────────────────────────────────────────────────┘
```

### 作用说明

- **你的业务代码**:不直接调 LLM,只调 MSAF 的 Agent / Workflow
- **MSAF 层**:提供 Agent 抽象,屏蔽 LLM 调用细节
- **MEAI 层**:定义 `IChatClient` 接口,让 LLM 可替换
- **Provider 层**:具体 LLM 的适配器,实现 `IChatClient`
- **LLM 服务**:实际的 AI 模型,通过 HTTP API 提供

**关键洞察**:换 LLM 只换 Provider 层配置,上层代码零改动。这是"可插拔"的基础。

## 3. 核心抽象关系图:5 大概念

```
                    ┌─────────────────────────────────┐
                    │         AIAgent (智能体)         │
                    │  ─────────────────────────────  │
                    │  + Instructions : string        │ ← 角色定位/行为规则
                    │  + Name         : string        │ ← 唯一标识
                    │  + Tools        : AIFunction[]  │ ← 可用工具
                    │  ─────────────────────────────  │
                    │  + RunAsync(input) : Response   │ ← 同步调用
                    │  + RunStreamingAsync() : IAsync │ ← 流式调用
                    │  + GetNewThread() : AgentThread │ ← 创建线程
                    └─────────────────────────────────┘
                          │                │           │
                          │                │           │
              ┌───────────┘                │           └────────────┐
              ▼                            ▼                        ▼
┌─────────────────────────┐  ┌─────────────────────────┐  ┌─────────────────────┐
│   AgentRunResponse       │  │     AgentThread          │  │    AIFunction        │
│   (执行响应)             │  │     (对话线程)           │  │    (工具函数)        │
│  ──────────────────────  │  │  ──────────────────────  │  │  ───────────────────  │
│  + Output                │  │  + Messages : List       │  │  + Name : string     │
│  + Messages              │  │  + Serialize()           │  │  + Description       │
│  + ToString() : string   │  │  + Deserialize()         │  │  + InvokeAsync()     │
│                          │  │                          │  │                      │
│  ← RunAsync 的返回值     │  │  ← 维护多轮对话历史      │  │  ← 让 Agent 能"做事" │
└─────────────────────────┘  └─────────────────────────┘  └─────────────────────┘
```

### 5 大概念作用速记

| 概念 | 一句话作用 | 类比 |
|------|-----------|------|
| **AIAgent** | 带身份/工具的 AI 调用封装 | 一个有专长的员工 |
| **AgentRunResponse** | Agent 执行后的返回结果 | 员工的工作报告 |
| **AgentThread** | 维护多轮对话的上下文 | 员工的笔记本 |
| **AIFunction** | 让 Agent 能调用外部代码 | 员工的工具箱 |
| **ChatClientAgent** | AIAgent 的最常用实现 | 具体某个员工 |

## 4. 单 Agent 调用流程图

```
用户请求
   │
   │ POST /api/app/agent-framework-app/hello-world
   │ Body: {"input": "你好"}
   ▼
┌──────────────────────────────────────────────────────────┐
│  AgentFrameworkAppService.HelloWorldAsync(input)         │
│  (ABP 自动 API 控制器)                                    │
└──────────────────────────────────────────────────────────┘
   │
   ▼
┌──────────────────────────────────────────────────────────┐
│  HelloWorldRunner.RunAsync(userInput)                    │
│  ┌──────────────────────────────────────────────────┐    │
│  │ 1. ChatClientFactory.Create()                    │    │
│  │    └─ 读取 appsettings.json 的 Llm 配置          │    │
│  │    └─ 构造 OpenAIClient + ApiKeyCredential       │    │
│  │    └─ 返回已绑定模型名的 ChatClient              │    │
│  └──────────────────────────────────────────────────┘    │
│                         │                                 │
│                         ▼                                 │
│  ┌──────────────────────────────────────────────────┐    │
│  │ 2. chatClient.CreateAIAgent(instructions, name)  │    │
│  │    └─ 创建 ChatClientAgent 实例 "greeter"        │    │
│  │    └─ Instructions 定义角色: "简洁问候助手"      │    │
│  └──────────────────────────────────────────────────┘    │
│                         │                                 │
│                         ▼                                 │
│  ┌──────────────────────────────────────────────────┐    │
│  │ 3. greeter.RunAsync(userInput)                   │    │
│  │    └─ MSAF 内部:                                 │    │
│  │       a. 拼 SystemMessage(Instructions)          │    │
│  │       b. 拼 UserMessage(userInput)               │    │
│  │       c. 调 ChatClient → HTTP POST 到 LLM        │    │
│  │       d. 接收 LLM 响应                           │    │
│  │       e. 包装为 AgentRunResponse 返回            │    │
│  └──────────────────────────────────────────────────┘    │
│                         │                                 │
│                         ▼                                 │
│  ┌──────────────────────────────────────────────────┐    │
│  │ 4. response.ToString() → "你好!...[from Agent]"  │    │
│  │    包装为 AgentTextOutputDto 返回                │    │
│  └──────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────┘
   │
   ▼
返回给用户
{
  "output": "你好!我是问候助手...[from Agent]",
  "elapsedMs": 1234,
  "trace": "HelloWorldRunner → greeter(Agent) → 输出"
}
```

### 关键步骤作用

| 步骤 | 作用 | 关键 API |
|------|------|----------|
| **1. Create ChatClient** | 建立与 LLM 的连接通道 | `OpenAIClient` + `GetChatClient(model)` |
| **2. CreateAIAgent** | 创建带身份的智能体 | `chatClient.CreateAIAgent(instructions, name)` |
| **3. RunAsync** | 触发 LLM 推理 | `agent.RunAsync(input)` → `AgentRunResponse` |
| **4. ToString** | 提取文本输出 | `response.ToString()` |

## 5. AgentThread 多轮记忆图

### 5.1 无 Thread(无状态)

```
第1轮: RunAsync("我叫张三")
   │
   ├─→ LLM 只看到: [User: "我叫张三"]
   ├─→ LLM 回复: "你好张三!"
   │
   └─→ ❌ 上下文丢失

第2轮: RunAsync("我叫什么?")
   │
   ├─→ LLM 只看到: [User: "我叫什么?"]    ← 没有上一轮!
   ├─→ LLM 回复: "抱歉,我不知道你的名字"
   │
   └─→ ❌ Agent 不记得了
```

### 5.2 有 Thread(有记忆)

```
         ┌─────────────────────────────────┐
         │        AgentThread              │
         │  ┌───────────────────────────┐  │
         │  │ Messages:                 │  │
         │  │  [0] User: "我叫张三"     │  │
         │  │  [1] Assistant: "你好张三"│  │
         │  │  [2] User: "我叫什么?"   │  │  ← 第2轮自动带上前2条
         │  └───────────────────────────┘  │
         └─────────────────────────────────┘
              ↑               ↑
              │               │
第1轮: RunAsync("我叫张三", thread)
   ├─→ Thread.Messages = [User:"我叫张三"]
   ├─→ LLM 看到完整历史 → 回复 "你好张三"
   └─→ Thread 追加: [Assistant:"你好张三"]

第2轮: RunAsync("我叫什么?", thread)        ← 同一个 thread!
   ├─→ Thread.Messages = [User:"我叫张三", Assistant:"你好张三", User:"我叫什么?"]
   ├─→ LLM 看到完整历史 → 回复 "你叫张三"
   └─→ Thread 追加: [Assistant:"你叫张三"]

✅ Agent 记住了!
```

### Thread 作用

- **维护对话历史**:同一 Thread 下的调用共享上下文
- **可序列化**:`Serialize()` 存到 DB / Redis,实现跨会话记忆
- **隔离性**:不同用户用不同 Thread,互不干扰

## 6. 工具调用时序图

```
用户: "北京天气怎么样?"
   │
   ▼
┌──────────────────────────────────────────────────────────┐
│  Agent.RunAsync("北京天气怎么样?")                       │
└──────────────────────────────────────────────────────────┘
   │
   │  [步骤1] MSAF 拼消息发给 LLM
   │  SystemMessage: "你是天气助手,用 get_weather 工具查天气"
   │  UserMessage: "北京天气怎么样?"
   │  Tools: [get_weather]
   ▼
┌──────────────────────────────────────────────────────────┐
│  LLM 推理                                                 │
│  "用户问北京天气,我有 get_weather 工具,应该调用它"        │
│  返回: FunctionCall { name="get_weather", args={city:"北京"} }│
└──────────────────────────────────────────────────────────┘
   │
   │  [步骤2] MSAF 自动执行工具
   ▼
┌──────────────────────────────────────────────────────────┐
│  AIFunction.InvokeAsync({"city": "北京"})                │
│  └─→ 你的代码: 查天气 API / 数据库                        │
│  └─→ 返回: "北京今天晴,25°C"                             │
└──────────────────────────────────────────────────────────┘
   │
   │  [步骤3] MSAF 把工具结果发回 LLM
   │  追加消息: ToolResult: "北京今天晴,25°C"
   ▼
┌──────────────────────────────────────────────────────────┐
│  LLM 二次推理                                             │
│  "工具返回北京晴25度,我整理成自然语言回复用户"            │
│  返回: "北京今天晴,气温25°C,适合出行。"                  │
└──────────────────────────────────────────────────────────┘
   │
   │  [步骤4] MSAF 包装为 AgentRunResponse 返回
   ▼
用户收到: "北京今天晴,气温25°C,适合出行。"
```

### 工具调用关键点

| 步骤 | 谁做的 | 作用 |
|------|--------|------|
| 1. 发消息给 LLM | MSAF | 告诉 LLM 有哪些工具可用 |
| 2. LLM 决定调工具 | LLM | LLM 判断"我需要用工具" |
| 3. 执行工具代码 | **MSAF 自动** | 调用你注册的 AIFunction |
| 4. LLM 整理回复 | LLM | 把工具结果转为自然语言 |

**开发者只需**:定义工具 + 绑定到 Agent,其余 MSAF 全自动。

## 7. Workflow 节点与边类型图

### 7.1 三种节点

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│   Agent 节点     │   │  Executor 节点  │   │  外部入口节点   │
│  ─────────────  │   │  ─────────────  │   │  ─────────────  │
│  调用 LLM 推理  │   │  执行自定义代码 │   │  工作流起点     │
│                 │   │  (不调 LLM)     │   │                 │
│  ChatClientAgent│   │  Executor<TIn,  │   │  WorkflowBuilder│
│  .AsWorkflowNode│   │    TOut>        │   │  自动管理       │
│                 │   │                 │   │                 │
│  例: 翻译Agent  │   │  例: 格式化输入 │   │  RunAsync(input)│
│      摘要Agent  │   │      聚合结果   │   │                 │
│      合规Agent  │   │      落库       │   │                 │
└─────────────────┘   └─────────────────┘   └─────────────────┘
      调 LLM               不调 LLM            数据入口
```

### 7.2 四种边

```
┌─────────────────────────────────────────────────────────────────┐
│  顺序边 (AddEdge)                                                │
│  ─────────────────                                              │
│  [A] ────→ [B]                                                  │
│  1对1,数据从 A 流向 B                                            │
│  用途: 串联执行,如 格式化→处理→落库                             │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  扇出边 (AddFanOutEdge)                                          │
│  ─────────────────────                                          │
│              ┌───→ [B1]                                         │
│  [A] ────────┼───→ [B2]    1对多,B1/B2/B3 并行执行              │
│              └───→ [B3]                                         │
│  用途: 多 Agent 并行处理同一输入(方案C核心)                     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  扇入边 (AddFanInEdge)                                           │
│  ─────────────────                                              │
│              ┌───┐                                              │
│  [A1] ───────┤   │                                              │
│  [A2] ───────┼───→ [C]    多对1,C 等待所有 A 完成后聚合          │
│  [A3] ───────┤   │                                              │
│              └───┘                                              │
│  用途: 汇总多个 Agent 的结果                                    │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│  条件边 (AddConditionalEdge)                                     │
│  ─────────────────────                                          │
│                  ┌─── (input.Contains("合同")) ──→ [ContractAgent]│
│  [Router] ───────┼─── (input.Contains("合规")) ──→ [ComplianceAgent]│
│                  └─── (else) ──────────────────→ [DefaultAgent]  │
│  1对1(动态),根据输入内容路由到不同节点                          │
│  用途: 智能分发,根据用户意图选 Agent                            │
└─────────────────────────────────────────────────────────────────┘
```

## 8. 顺序 Workflow 数据流图

```
用户输入: "请把这段话翻译成英文: 你好世界"
   │
   ▼
┌──────────────────────────────────────────────────────────────┐
│  Workflow.RunAsync(input)                                     │
└──────────────────────────────────────────────────────────────┘
   │
   ▼
┌──────────────────────────────────────────────────────────────┐
│  [节点1: FormatExecutor]  ← 自定义 Executor,不调 LLM         │
│  作用: 提取"翻译成英文: "后面的内容                            │
│  输入: "请把这段话翻译成英文: 你好世界"                       │
│  输出: "你好世界"                                             │
└──────────────────────────────────────────────────────────────┘
   │ AddEdge
   ▼
┌──────────────────────────────────────────────────────────────┐
│  [节点2: TranslatorAgent]  ← Agent 节点,调 LLM                │
│  作用: 翻译文本                                                │
│  Instructions: "你是翻译助手,把中文翻译成英文"                │
│  输入: "你好世界"                                              │
│  输出: "Hello World"                                          │
└──────────────────────────────────────────────────────────────┘
   │ AddEdge
   ▼
┌──────────────────────────────────────────────────────────────┐
│  [节点3: SinkExecutor]  ← 自定义 Executor,不调 LLM            │
│  作用: 格式化输出 + 记日志                                     │
│  输入: "Hello World"                                          │
│  输出: "翻译结果: Hello World [耗时 1.2s]"                    │
└──────────────────────────────────────────────────────────────┘
   │ WithOutputFrom(node3)
   ▼
返回给用户: "翻译结果: Hello World [耗时 1.2s]"
```

### 各节点作用

| 节点 | 类型 | 调 LLM? | 作用 |
|------|------|---------|------|
| FormatExecutor | Executor | ❌ | 预处理输入,提取关键内容 |
| TranslatorAgent | Agent | ✅ | LLM 翻译 |
| SinkExecutor | Executor | ❌ | 后处理,格式化输出 |

**设计模式**:Executor 负责"机械活",Agent 负责"脑力活"。

## 9. Fan-Out / Fan-In 并行编排图

```
用户输入: "分析这份合同: ..."
   │
   ▼
┌──────────────────────────────────────────────────────────────┐
│  [DispatchExecutor]  ← 分发节点                               │
│  作用: 把输入分发给3个Agent(可加预处理)                       │
└──────────────────────────────────────────────────────────────┘
   │
   │ AddFanOutEdge ──── 同时分发给3个节点(并行!)
   │
   ├──────────────────┬──────────────────┐
   ▼                  ▼                  ▼
┌────────────┐  ┌────────────┐    ┌────────────┐
│ Translator │  │ Summarizer │    │ Compliance │
│  Agent     │  │   Agent    │    │   Agent    │
│            │  │            │    │            │
│ 翻译合同   │  │ 生成摘要   │    │ 合规审查   │
│ (调LLM)    │  │ (调LLM)    │    │ (调LLM)    │
└────────────┘  └────────────┘    └────────────┘
   │                  │                  │
   │ "Contract..."   │ "摘要:..."      │ "合规: 通过"
   │                  │                  │
   └──────────────────┴──────────────────┘
   │
   │ AddFanInEdge ──── 3个结果汇入聚合节点(等待全部完成)
   ▼
┌──────────────────────────────────────────────────────────────┐
│  [AggregateExecutor]  ← 聚合节点                              │
│  作用: 把3个Agent的结果合并成最终报告                          │
│  输入: ["Contract...", "摘要:...", "合规: 通过"]             │
│  输出: "## 合同分析报告\n\n### 翻译\n...\n### 摘要\n...\n### 合规\n..."│
└──────────────────────────────────────────────────────────────┘
   │
   ▼
返回给用户: 完整分析报告
```

### 并行执行要点

```
时间轴:
t=0s   ┌─ Translator 开始 (耗时3s)
       ├─ Summarizer 开始 (耗时2s)     ← 3个同时开始!
       └─ Compliance 开始 (耗时4s)
t=2s   └─ Summarizer 完成 ✓
t=3s   └─ Translator 完成 ✓
t=4s   └─ Compliance 完成 ✓  ← 最慢的决定总耗时
       │
       ▼
t=4s   Aggregate 开始(所有源完成才执行)
t=4.5s Aggregate 完成 → 返回
```

**总耗时 ≈ max(3, 2, 4) + 0.5 = 4.5s**(不是 3+2+4=9s)
